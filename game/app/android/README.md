# 봄날의 행진 — 안드로이드 휴대폰 앱

휴대폰(안드로이드)에 직접 설치해서 노는 판입니다. 인터넷 없이도 돌아가고, 저장은 휴대폰 안에 됩니다.

## 1. 설치 파일은 어디에?

**`C:\시라이스\.cache\release\android\`** 폴더에 두 개가 있어요. (언제나 여기 있어요)

| 파일 | 무엇 | 언제 쓰나 |
|---|---|---|
| `봄날의행진-0.1.0-release.apk` | 우리 열쇠로 서명한 **정식판** | **대표님은 이걸 쓰세요** |
| `봄날의행진-0.1.0-debug.apk` | 개발용 (컴퓨터로 속을 들여다볼 수 있음) | 문제를 찾을 때만 |

> 같은 파일을 한 칸 위 `C:\시라이스\.cache\release\` 에도 복사해 두지만, **PC 설치판을 새로 만들면 그쪽 파일은 지워져요.** 안 보이면 `android` 폴더 안을 보세요.
>
> 두 파일은 서명이 달라서 서로 덮어 설치가 안 됩니다. 한쪽만 계속 쓰세요.
> (바꾸려면 앱을 지우고 다시 설치해야 하는데, 지우면 **저장한 마을도 같이 지워져요**.)

## 2. 휴대폰으로 옮기기 (셋 중 편한 것)

- **USB 선**: 휴대폰을 컴퓨터에 꽂고, 휴대폰 알림에서 "파일 전송"을 고른 뒤, apk 파일을 휴대폰의 `Download`(다운로드) 폴더에 복사
- **구글 드라이브**: 컴퓨터에서 드라이브에 올리고, 휴대폰 드라이브 앱에서 내려받기
- **메일**: 나에게 메일로 보내고 휴대폰에서 첨부 파일 받기

## 3. 설치하기

1. 휴대폰의 **내 파일**(또는 "파일") 앱에서 `다운로드` 폴더를 열고 apk 파일을 누릅니다.
2. "출처를 알 수 없는 앱" 안내가 나오면 → **설정** → 이 앱(내 파일 / 드라이브 / 크롬 등)에 **"이 출처 허용"** 을 켭니다 → 뒤로 가기.
3. **설치**를 누릅니다.
4. "Play 프로텍트" 경고가 나오면 → **세부정보 더보기** → **무시하고 설치** (우리가 만든 앱이라 구글이 아직 모를 뿐이에요).
5. 홈 화면에 주인공 얼굴 아이콘 **"봄날의 행진"** 이 생깁니다.

## 4. 켜면 이렇게 돼요

- 휴대폰을 **가로로** 들고 놉니다 (거꾸로 들어도 화면이 따라 돌아요).
- 위쪽 시계·배터리 줄과 아래쪽 버튼 줄은 숨겨져요. 화면 가장자리를 쓸어 넘기면 잠깐 보여요.
- 노는 동안 화면이 꺼지지 않아요.
- 처음 켤 때 몇 초 동안 "불러오는 중…" 이 나와요.
- 손가락 하나로 끌면 화면 이동, 두 손가락을 벌리면 확대, 두 손가락을 비틀면 회전, 짧게 누르면 고르기.
- **건물 짓기** (휴대폰용 방식):
  1. 아래 메뉴에서 건물 단추를 누릅니다. 단추 아래 작은 글씨가 **짓는 데 드는 값**이에요 (예: 판자2 돌2).
  2. 화면 가운데에 **미리 보기**가 바로 나와요. 바닥이 초록이면 지을 수 있고, 빨강이면 안 되는 자리예요. 노란 화살표가 정문이에요.
  3. 원하는 곳을 누르면 미리 보기가 그리로 옮겨 가요 (아직 안 지어져요). ⟲ ⟳ 로 방향을 돌려요.
  4. **✔ 짓기**를 누르면 지어요. (같은 자리를 한 번 더 눌러도 돼요)
  - 처음 마을회관 자리를 정할 때도 똑같아요.
- 위쪽 둘째 줄에 창고의 물건(통나무·판자·빵·생선…)이 **모두** 보여요.
- **홈 버튼**을 누르거나 화면을 끄면 → 소리가 멈추고 마을이 자동 저장돼요. 다시 켜면 소리가 돌아와요.
- **뒤로 가기**를 누르면 "게임을 끝낼까요?" 하고 물어봐요. "끝내기"를 누르면 저장한 뒤 닫혀요.
- 다음에 켜면 "저장된 마을이 있어요 → 이어하기" 가 나와요.
- 새 판(예: 0.2.0)을 같은 방법으로 설치하면 그대로 덮어써지고, **저장은 남아요**.

## 5. 느낌을 알려 주세요!

실제 휴대폰에서 해 본 느낌이 제일 중요해요. 이런 걸 알려 주시면 바로 고칠게요.
- 휴대폰 기종 (예: 갤럭시 S23, 갤럭시 A54)
- 느리거나 끊기는 곳, 뜨거워지는지
- 글자·버튼이 너무 작거나 누르기 어려운 곳
- 이상하게 보이는 화면 (스크린샷: 전원 + 소리 줄이기 버튼 동시에)

## (만드는 쪽 메모) 다시 만들기

저장소의 `game` 폴더에서:

```bash
node tools/build/build_android.mjs              # 게임 묶음(www) → 안드로이드 프로젝트 정리 → APK 두 개 → .cache/release/
node tools/build/build_android.mjs --web-only   # 게임 묶음(www)만 (휴대폰 화면 시험용, 몇 초)
node tools/build/build_android.mjs --setup      # 새 PC: 자바·안드로이드 도구를 .cache 에 내려받아 설치 (라이선스 동의 포함)
#   --no-release : 정식판 건너뛰기,  --clean : www 를 처음부터 (모델 압축 다시)
PLAYWRIGHT_BROWSERS_PATH=../.cache/pw-browsers node tools/test/android_test.mjs   # 시험 (APK 검사 + 휴대폰 화면 플레이, 창 안 띄움)
```

- 빌드는 자바·그래들 같은 도구를 모두 숨김(windowsHide)으로 돌려 검은 명령 창이 화면에 뜨지 않는다.
- 시험은 화면에 창을 띄우지 않는다 (숨은 크롬 + 진짜 그래픽카드). 휴대폰 크기 844x390, 터치, 배율 3 으로 켜기·짓기·끌기·확대·회전·저장·이어하기를 해 본다.
- 안드로이드 가상 휴대폰(에뮬레이터)은 이 PC 에서 돌리지 않았다: 윈도우의 가상화 기능(하이퍼바이저)이 꺼져 있어 켜려면 컴퓨터 설정을 바꿔야 하기 때문. 그래서 **진짜 휴대폰에서의 확인이 꼭 필요하다.**

- 걸리는 시간: 처음 약 3분(빌드 도구 내려받기), 그다음부터 약 20~30초.
- 설치물은 모두 `C:\시라이스\.cache\` 안: `jdk`(자바 21), `android-sdk`(안드로이드 35), `gradle`(빌드 도구 창고). 컴퓨터 설정은 바꾸지 않습니다.
- **정식판 서명 열쇠**: `C:\시라이스\.cache\android-keystore\` (처음 빌드 때 자동으로 만듦). 이 폴더를 잃어버리면 같은 앱으로 업데이트를 할 수 없으니 **꼭 따로 백업**하고, 저장소(git)에는 절대 올리지 않습니다.
- 이 폴더 구조
  - `package.json`, `capacitor.config.json` — 앱 껍데기(Capacitor 7) 설정. 앱 이름 `봄날의 행진`, 앱 아이디 `kr.springmarch.game` (바꾸면 다른 앱이 되어 저장이 이어지지 않음)
  - `www/` — 휴대폰 안에 들어가는 게임 묶음. 빌드할 때마다 새로 만듦 (git 에 안 올림)
  - `android/` — 안드로이드 프로젝트. `MainActivity.java`(전체 화면·화면 안 꺼짐·뒤로 가기·저장 신호), 아이콘, 가로 고정 등은 **빌드 스크립트가 매번 다시 써 넣으므로** 고칠 때는 `tools/build/build_android.mjs` 를 고친다.
- **휴대폰 화면 배치·손가락 짓기**는 이제 본판(`game/src/ui/hud.css`, `hud.js`, `main.js`)이 직접 맡는다 (웹 플레이 링크·PC 판도 같음):
  자원 줄은 위쪽 둘째 줄로(모든 물건이 보이게), 휴대폰 가로에서도 건물 값 보이기, 분류 탭 한 줄,
  손가락 짓기는 "미리 보기 → 땅을 누르면 옮기기 → ✔ 짓기(또는 같은 자리 한 번 더)".
- 게임 쪽 신호: 앱이 뒤로 가면 `window` 에 `sm-app-pause`, 돌아오면 `sm-app-resume` 이벤트가 온다. `www/index.html` 안 도우미가 소리를 멈추고 `game.saver.autoSave('hide')` 를 부른다.
