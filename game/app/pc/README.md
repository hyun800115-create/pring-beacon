# 봄날의 행진 — 윈도우 PC 판

게임을 윈도우 컴퓨터에 **프로그램처럼 설치**하거나, **설치 없이 바로** 켤 수 있게 만든 판입니다.
인터넷이 없어도 돌아가고, 저장한 마을은 컴퓨터에 남아서 껐다 켜도 이어서 할 수 있어요.

## 만들어진 파일 (저장소의 `.cache\release` 폴더)

| 파일 | 쓰는 법 |
|---|---|
| `봄날의행진-설치-0.1.0.exe` | **설치판.** 두 번 누르면 바로 설치되고 게임이 켜져요. 바탕 화면과 시작 메뉴에 「봄날의 행진」 바로 가기가 생겨요. |
| `봄날의행진-바로실행-0.1.0.exe` | **바로 실행판.** 설치 없이 이 파일 하나만 두 번 누르면 켜져요. USB 에 넣어 다른 컴퓨터에서 해 볼 때 좋아요. (켤 때 몇 초 더 걸려요) |
| `win-unpacked\SpringMarch.exe` | 시험용으로 풀어 둔 것. 이 폴더째로도 켤 수 있어요. |

파일 크기는 각각 약 117MB 입니다 (게임 그림·모델·소리 + 화면 엔진).

## 설치하는 법

1. `봄날의행진-설치-0.1.0.exe` 를 두 번 누릅니다.
2. **파란 경고 창(Windows의 PC 보호)이 뜨면**: `추가 정보` 를 누르고 → `실행` 을 누릅니다.
   - 우리 게임에 **회사 인증서(디지털 서명)** 를 붙이지 않아서 뜨는 창이에요. 바이러스라는 뜻은 아닙니다.
   - 나중에 정식으로 팔 때는 인증서(1년에 수십만 원)를 사서 붙이면 이 창이 안 뜹니다.
3. 잠깐 기다리면 설치가 끝나고 게임이 켜집니다. 다음부터는 바탕 화면의 「봄날의 행진」 을 누르세요.

- 설치되는 곳: `C:\Users\<사용자>\AppData\Local\Programs\봄날의 행진` (관리자 권한 필요 없음)
- 지우기: `설정 → 앱 → 설치된 앱` 에서 「봄날의 행진」 → 제거. (저장한 마을은 지워지지 않고 남아요)

## 게임 조작 (PC 판에서 더 생긴 것)

- **F11** (또는 Alt+Enter): 전체 화면 켜기/끄기
- 창 크기·위치는 기억해 두었다가 다음에 그대로 열어요. 화면이 작은 노트북에서는 화면에 꽉 차게 열려요.
- 창은 가로 1024 × 세로 600 까지 줄일 수 있어요. 가로가 1280 보다 좁으면 위쪽 막대가 휴대폰 판처럼 한 줄로 작아져서
  (집 칸 수·쉬는 사람·봉화 숫자는 숨겨짐) 소리·서리골 버튼이 화면 밖으로 밀리지 않아요. 화면 배율이 큰 노트북(150~175%)도 같아요.
- 게임을 두 번 켜도 창은 하나만 열려요 (저장이 엉키지 않게).
- 게임 안의 바깥 인터넷 주소는 게임 창이 아니라 평소 쓰는 인터넷 창으로 열려요.

## 저장은 어디에?

- `C:\Users\<사용자>\AppData\Roaming\봄날의 행진` 폴더 (설치판·바로 실행판 모두 같은 곳).
- 아침마다, 그리고 창을 닫을 때 저절로 저장돼요. 위쪽 💾 버튼으로 바로 저장할 수도 있어요.
- 다른 컴퓨터로 옮기려면 이 폴더를 통째로 복사하면 됩니다.

## 새 판 만들기 (Claude 가 하는 일, 참고용)

저장소의 `game` 폴더에서:

```
node tools/build/build_app.mjs              # 게임 묶기 + 설치판 + 바로 실행판 (1분쯤)
node tools/build/build_app.mjs --www-only   # 게임 묶기만 (시험용, 몇 초)
node tools/test/app_test.mjs                # 앱을 진짜로 켜서 시험 (풀어 둔 앱 win-unpacked)
node tools/test/app_test.mjs --dev          # 개발용 앱으로 시험
node tools/test/app_test.mjs --portable     # 바로 실행판 .exe 를 켜서 시험
node tools/test/app_test.mjs --installer    # 설치 파일 속을 풀어서(설치는 안 함) 그 안의 앱으로 시험
```

- **시험할 때 창은 화면에 뜨지 않아요.** 시험은 숨김 모드(환경 변수 `SM_HIDDEN=1`)로 켜서,
  창을 한 번도 보여 주지 않고 화면 밖에서 그래픽카드로 그립니다(초당 60번). 대표님이 컴퓨터를 쓰는 중에도 방해되지 않아요.
  - 숨김 모드에서는 F11 전체 화면을 '창을 모니터 크기로 키우기'로 흉내 냅니다 (진짜 전체 화면은 윈도우가 창을 억지로 보여 주기 때문).
  - 보이는 창으로 시험하고 싶을 때만 `--show` 를 붙입니다.
- 설치 파일 시험은 진짜로 설치하지 않습니다(바탕 화면·시작 메뉴를 건드리지 않게). 7-Zip 으로 속을 풀어서 안에 앱·게임 파일·지우기 프로그램이 다 있는지 보고, 그 앱을 켜 봅니다.
- 시험 결과(그림·기록)는 `.cache\app-pc\test`, `.cache\app-pc\test-installer` 에 남아요.

- 처음 한 번은 `game/app/pc` 폴더에서 `npm install` (화면 엔진 Electron 과 포장 도구를 받아요).
- 판 번호는 `game/app/pc/package.json` 의 `"version"` 을 바꾸면 됩니다.
- 앱 코드: `main.js` (창·전체 화면·게임 파일 보여 주기·저장 지키기), `preload.js` (게임에서 쓸 수 있는 `window.smApp`: `pc`, `fullscreen()`, `quit()`).
- 게임 파일은 `.cache/app-pc/www` 에 한 벌 묶여서 설치판 안 `resources/www` 로 들어가요. 아이콘은 `.cache/app-pc/build/icon.ico`.
