# 02. 도구와 환경 — 무엇을 썼고, 어떻게 설치하나

> **대표님용 요약**
> - 그림: **Blender 5.2** (무료 3D 프로그램)를 파이썬으로 조종해서 캐릭터·건물을 3D로 만들고, 사진처럼 렌더링해서 게임용 그림 조각(스프라이트)으로 잘랐어요.
> - 이펙트·UI·바닥: 파이썬 그림 라이브러리(**Pillow, numpy**)로 직접 그렸어요.
> - 소리: 파이썬으로 악기 소리를 **수학적으로 합성**하고 **ffmpeg**로 mp3/ogg 파일로 만들었어요.
> - 게임: **Phaser 3.90** (웹 게임 엔진). 휴대폰 브라우저에서 바로 돌아가요.
> - 테스트: **Playwright + 크롬**을 화면 없이 띄워서 사람처럼 자동으로 플레이.
> - 전부 **무료 도구**이고, 클라우드 컴퓨터(CPU 4개, 메모리 15GB)에서 돌렸어요.

## 1. 실제로 쓴 도구와 버전

| 용도 | 도구 | 버전 | 비고 |
|---|---|---|---|
| 3D 렌더 | Blender (파이썬 모듈 `bpy`) | 5.2.2 LTS | `pip install bpy`. 렌더 엔진은 **Cycles(CPU)** + OpenImageDenoise. EEVEE·Workbench는 화면 장치(EGL)가 없어 헤드리스에서 실패 |
| 파이썬 | CPython | 3.13.16 | bpy 5.2 휠이 3.13 용 |
| 이미지 처리 | numpy / Pillow | 2.5.3 / 12.3.0 | 프로시저럴 그림, 아틀라스 패킹 |
| 색 압축 | imagequant (libimagequant) | 1.1.5 | PNG를 192~256색 팔레트로 → 3~4배 작게, Pillow 기본 양자화보다 줄무늬(밴딩)가 훨씬 적음 |
| 사운드 필터 | scipy | 1.18.1 | 별도 venv `/tmp/fv_audio_venv` (오디오 스크립트가 자동으로 그 파이썬으로 재실행) |
| 오디오 인코딩 | ffmpeg | 6.1.1 | libvorbis(ogg), libmp3lame(mp3), ebur128(음량 측정) |
| 게임 엔진 | Phaser | 3.90.0 | `lib/phaser.min.js` 로 포함(빌드 단계 없음, ES 모듈) |
| 런타임 | Node.js | 22 | 테스트 서버, 빌드 |
| 브라우저 테스트 | Playwright + Chromium | 1.56.1 | 전역 npm 패키지, 브라우저는 `/opt/pw-browsers`. 헤드리스 WebGL은 SwiftShader(소프트웨어)라 FPS는 낮게 나옴(실기기와 무관) |
| 번들러 | esbuild | ^0.25 | 플레이 링크용 단일 스크립트(`game.js`) 만들기 (`tools/build`) |

## 2. 클라우드 컨테이너 환경 (Claude Code 원격 세션)
- CPU 4코어, 메모리 15GB, 디스크 여유 약 30GB.
- 네트워크: **PyPI, npm 만 사용 가능**하다고 가정. `download.blender.org`, `huggingface.co`, `cdnjs` 등은 차단(403) → Blender는 PyPI의 `bpy` 로, AI 모델은 사용 불가.
- 컨테이너는 쉬면 사라짐 → 설치는 세션마다 다시(아래 명령), **작업물은 수시로 커밋·푸시**.
- 워크플로(여러 에이전트) 동시 실행 수 = CPU-2 = **2**.

## 3. 설치 명령 (새 세션에서 한 번)
```bash
# 1) Blender 모듈 (약 1~2분)
python3 -m venv /tmp/bvenv
/tmp/bvenv/bin/pip install bpy==5.2.2 numpy pillow imagequant
/tmp/bvenv/bin/python -c "import bpy; print(bpy.app.version_string)"   # 5.2.2 LTS

# 2) 시스템 파이썬에 팔레트 압축 (char_pack.py 등이 사용)
python3 -m pip install imagequant

# 3) 사운드용 scipy
python3 -m venv --system-site-packages /tmp/fv_audio_venv
/tmp/fv_audio_venv/bin/pip install scipy

# 4) 배포 번들러 (게임 폴더 기준)
cd <게임폴더>/tools/build && npm install

# 5) 확인
ffmpeg -hide_banner -encoders | grep -E "libvorbis|libmp3lame"
node -e "require(require('child_process').execSync('npm root -g').toString().trim()+'/playwright')" && echo playwright-ok
```
- 렌더 테스트 한 장: `/tmp/bvenv/bin/python -c "import sys; sys.path.insert(0,'tools/blender'); import bl_common"` 가 오류 없이 끝나면 준비 완료.
- Python 버전이 3.13이 아니면: `uv python install 3.13` 후 `uv venv -p 3.13 /tmp/bvenv` 로 만들기.

## 4. 대표님 PC에서 돌리기 (선택)
- **Blender 그림**: blender.org 에서 Blender 4.x~5.x 설치 → 터미널에서
  `blender -b -P tools/blender/char_render.py -- --chars player`
  (모든 Blender 스크립트는 `-- ` 뒤에 옵션을 받도록 만들어져 있음). 패킹은 일반 파이썬 + `pip install numpy pillow imagequant` 후 `python tools/blender/char_pack.py`.
- **이펙트/UI/바닥**: `pip install numpy pillow` 후 `python tools/fx/gen_fx.py` 등.
- **소리**: `pip install numpy scipy pillow`, ffmpeg 설치 후 `python tools/audio/build_audio.py`.
- **게임 실행**: 게임 폴더에서 `npx serve` 또는 `python -m http.server` → 브라우저로 `http://localhost:포트/` 열기. (파일을 더블클릭하면 브라우저 보안 때문에 안 열림)
- PC는 GPU가 있으니 Blender 렌더가 클라우드보다 훨씬 빠를 수 있어요(Cycles GPU 설정은 `bl_common.setup_render` 에서 `device='GPU'` 로).
