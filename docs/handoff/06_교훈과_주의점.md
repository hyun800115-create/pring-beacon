# 06. 교훈과 주의점 — 만들면서 실제로 부딪힌 문제와 해결법

> **대표님용 요약**
> - 같은 실수를 반복하지 않도록, 서리마을을 만들면서 **실제로 생긴 문제 30여 가지와 해결법**을 모았어요.
> - 가장 큰 교훈 세 가지: ① 규칙(계약서)을 먼저 정하면 여러 팀이 동시에 일해도 안 엉킨다. ② 게임은 **봇이 실제로 끝까지 플레이**해 봐야 막히는 곳이 보인다. ③ 작업 중인 AI 팀에게 말을 걸면 팀이 복제되는 사고가 났다 → 멈추고 새로 시작하는 게 안전하다.

## 1. 그림 (Blender)
| 문제 | 원인 | 해결 |
|---|---|---|
| EEVEE·Workbench 렌더가 죽음 | 클라우드엔 화면 장치(EGL)가 없음 | **Cycles(CPU) + OpenImageDenoise** 만 사용. 128px 한 장 0.2~0.8초 |
| 색이 탁하게 나옴 | Blender 기본 색 변환(AgX/Filmic)이 채도를 낮춤 | `view_transform='Standard'` (bl_common 에 고정) |
| 그림자 받이(shadow catcher) 주변에 옅은 회색 막 | 하늘빛 차폐가 투명 배경에 남음 | `pack_utils.clean_alpha(floor=10)` + 가장자리 페이드(`border_fade`) |
| 흰 파카가 눈밭에서 안 보임 | 흰색 위의 흰색 | 모든 캐릭터 프레임에 **1px 부드러운 외곽선** 후처리 |
| 아틀라스가 너무 큼 (캐릭터 10MB+) | 128px RGBA 수천 장 | **잘라내기(trim) + libimagequant 192~256색** → 3~4배 감소. Pillow 기본 양자화는 머리·파카에 줄무늬가 생겨서 안 씀 |
| 좌우 반전(flipX) 시 캐릭터가 옆으로 튀는지 걱정 | 잘라낸(trimmed) 프레임 + 반전 | Phaser 3.90 은 sourceSize 기준이라 정상 — 검수에서 프레임별 중심 ±3px 확인 |
| 들고 있는 탑이 촌장 얼굴을 가림 | 가슴 높이 carryPoint + 큰 아이템 | 손에 들 때 아이템 0.55~0.65배(`carryScale`), 최종적으로 **탑을 머리 위에** 올림(`balance.carryOnHead`) |
| 표정이 작아서 안 보임 | 80px 캐릭터에 실제 비율 얼굴 | 눈·입·볼을 **과장해서 크고 두껍게**, 3배 확대로 1:1 가독성 확인 |
| 할아버지 입이 수염에 묻힘, 팔 올린 포즈가 머리에 가려짐 | 3D 겹침 | 입을 수염 위로, 팔은 머리 옆 목표점으로 |
| 가공소 작업 애니메이션이 거의 안 움직임 | 발광 세기만 바꿈 | 불꽃·연기·톱밥·흔들리는 고기 등 **눈에 띄는 움직임**을 프레임에 직접 넣음 (프레임당 700~2,500px 변화) |

## 2. 이펙트·UI
| 문제 | 해결 |
|---|---|
| 더하기(ADD) 블렌드 반짝이·불꽃이 **흰 눈 위에서 사라짐** | 모두 NORMAL 블렌드 + 진한 중심색과 부드러운 테두리로 그림 |
| 9-slice 패널을 작게 늘이면 깨짐 | 여백 합계보다 작게 쓰지 않기 (패널 최소 약 52px 높이) — 매니페스트에 여백 기록 |
| 이음매 없는 바닥 텍스처 | 주기적(periodic) 노이즈로 생성, 2×2로 붙여서 눈으로 확인 |
| 휴대폰에서 화면이 흐릿 | 캔버스를 720px 고정으로 그려서 확대됨 → 기기 해상도(최대 2배)로 그리고, 약한 GPU면 1배로 자동 전환 |

## 3. 소리
| 문제 | 원인 | 해결 |
|---|---|---|
| 반복 음악이 이어지는 곳에서 '틱' | 사람 느낌 내려고 당긴 음이 0초 앞에서 잘림 | 루프 시작에 꼬리를 감아 넣고, 2차 차분으로 클릭 수치 검사 |
| **크롬에서 ogg 루프가 끊김** | 크롬의 오디오 해독이 Vorbis 끝 자르기 정보를 무시하고 최대 22ms 패딩을 붙임 | 루프 길이를 **Vorbis 블록 경계에 맞춤** + 게임에서 길면 잘라 재생(`Audio.trimLoops`) |
| 여러 소리가 겹치면 찢어짐 | 웹오디오는 합쳐서 0dB에서 잘림 | 전체 -2dB 여유(HEADROOM), 매니페스트 볼륨으로 균형 |
| 창이 비활성일 때 소리가 쌓였다가 한꺼번에 터짐 | 멈춘 오디오 컨텍스트에 예약됨 | 컨텍스트가 돌아갈 때만 재생 |
| 일꾼 소리가 끊임없이 들림 | 화면 밖 일꾼까지 전부 재생 | 화면 안/근처만 재생 |
| 사람이 직접 못 들어봄 | AI는 소리를 못 들음 | 수치(음량·피크·스펙트럼)·파형 그림으로 검사 → **출시 전 사람이 꼭 들어볼 것** |

## 4. 게임플레이 (봇 플레이로 찾음)
| 문제 | 해결 |
|---|---|
| **광부 고용 발판이 광산 입구 충돌 범위 안** → 게임 완료 불가 (치명) | 발판 위치 이동 + "발판에 실제로 설 수 있는지" 검사 스크립트 |
| **산 손님이 사라지지 않음** → 9분쯤 시장 마비, 점점 느려짐 (치명) | 퇴장 경로를 걸을 수 있는 곳에서 끝나게 + 화면 밖이면 삭제 + 30초 안전 타이머 |
| 일부만 받은 손님이 줄을 영원히 막음 | 다른 음식으로 바꿔 받고, 받은 만큼만 계산 |
| 가방이 날것으로 가득 + 가공소 꽉 참 → 꼼짝 못함 | '버리기' 발판(모닥불) + 꽉 찬 가공소 재료는 채집 안 함 |
| 플레이어가 끝까지 배달만 함 (재미 ↓) | 완성 후 **짐꾼(배달 일꾼)** 고용 → 자동 수익 |
| 업그레이드가 오히려 손해 | 가격 낮추고 효과 키움, 봇으로 완료 시간 비교 (최적 14분, 일반 18분) |
| 발판 위를 지나가기만 해도 돈이 빠짐 | 0.5초 서 있어야 시작 + 다음 단계는 발판에서 내려갔다 와야 |

## 5. 안정성·배포
| 문제 | 해결 |
|---|---|
| 깨진 저장 데이터 → 영원히 빈 화면 | 불러올 때 값 정리(sanitize), 그래도 실패하면 따로 보관 후 새로 시작 |
| 게임 루프 안 오류 → 그대로 멈춤 | "새로고침 / 처음부터" 안내 오버레이 |
| 기획자가 balance.js 에 0 이나 빈 값 입력 → 진행 불가 | 시작할 때 값 검사·자동 보정(`data/balanceCheck.js`) |
| localStorage 접근 자체가 오류 (비공개 창, 샌드박스) | 모든 접근을 try/catch, 없어도 플레이 가능 |
| 플레이 링크(아티팩트) 페이지 규칙 | 본문만 있는 HTML, 파일 255개 이하, 경고창 금지, 소리는 터치 후 — `tools/build/build_artifact.mjs` 가 처리 |
| 출처 없는 샌드박스에서 파일 로딩 실패 | 모든 에셋을 스크립트 안에 넣은 `--inline` 빌드 (대비책) |
| 다른 팀이 코드 수정 중일 때 배포판 만들기 | `git worktree` 로 마지막 커밋을 떼어 빌드 |
| 첫 로딩이 무거움 (약 12MB) | 큰 PNG는 WebP, 마을 음악·환경음은 타이틀 뒤에 늦게 불러오기 |

## 6. AI 팀(에이전트) 운영
| 사고 | 교훈 |
|---|---|
| 백그라운드 작업이 멈춘 줄 알고 다시 띄움 → 실제로는 계속 돌고 있어서 **같은 팀이 두 개** | 다시 띄우기 전에 작업 기록 파일의 수정 시각과 실행 중인 프로세스를 확인 |
| 작업 중인 에이전트에게 메시지를 보냄 → **에이전트가 복제**되어 같은 파일을 서로 덮어씀 | 실행 중인 에이전트에게는 메시지 금지. 멈추고(TaskStop) 상태를 확인한 뒤, "디스크에 있는 것부터 이어서" 하라고 새로 띄움 |
| 멈추기(TaskStop)를 하면 복제본과 원본이 같이 멈춤 | 멈춘 뒤 파일·프로세스가 조용해진 것을 확인하고 새로 시작 |
| 4코어에서 워크플로 동시 실행이 2개뿐 | 큰 작업은 워크플로를 둘로 나눠 동시에 띄움 |
| 컨테이너·세션이 끊김 | 수시로 커밋·푸시, 생성 스크립트는 이어하기 가능하게, 캐시는 `/tmp` |
| 기획 범위가 계속 커짐 | 버전별 로드맵(v2, v3 …)으로 나누고, 매 버전 끝에 플레이 링크 |
