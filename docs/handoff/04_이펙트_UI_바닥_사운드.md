# 04 · 이펙트 · UI · 바닥 · 이모티콘 그림과 음악 · 효과음 만들기

> **대표님용 요약 — 이 문서는 무엇인가요?**
>
> - 반짝이·연기·물보라 같은 **효과 그림**, 버튼·아이콘·말풍선 같은 **화면 그림**, 눈밭·바닥 무늬, 이모티콘, 그리고 **배경음악·바람 소리·효과음**을 어떻게 만들었는지 정리한 설명서예요.
> - 이 그림과 소리는 3D 프로그램이 아니라 **짧은 프로그램이 직접 그리고, 악기 소리까지 직접 합성**한 거예요. 그래서 같은 명령을 다시 실행하면 언제나 똑같은 결과가 나오고, 색·크기·분위기를 바꿔 몇 초~1분 만에 다시 만들 수 있어요. 남의 소리나 그림을 가져온 게 아니라서 저작권 걱정도 없어요.
> - 새 세틀러식 게임에 필요한 **길 바닥, 공사 먼지, 건물 완공 축하음, 건물마다 다른 작업 소리, 영토 지도 화면 그림**도 같은 도구로 만들 수 있고, 방법을 5장에 적어 두었어요.
> - Claude는 소리를 귀로 들을 수 없어서 숫자로 검사해요. 그래서 소리는 **대표님이 미리듣기 페이지로 직접 들어보고 의견을 주시는 것**이 가장 중요해요.
>
> 아래부터는 새 프로젝트의 Claude가 읽는 기술 설명입니다.

## 1. 공통 원칙 (그림·소리 모두)

1. **코드가 원본이다.** PNG·OGG는 결과물일 뿐이고, 모든 난수는 고정 시드(`np.random.default_rng(seed)`, `S.rng(seed)`)라서 같은 명령 → 같은 바이트. 보고서 기준 FX/UI/바닥은 2회 연속 빌드가 동일, 이모티콘도 동일, 오디오도 깨끗한 상태에서 2회 빌드가 바이트 동일.
2. **경로는 스크립트 위치 기준.** 모든 스크립트가 `HERE = os.path.dirname(os.path.abspath(__file__))`, `ROOT = HERE/../..` 로 게임 루트를 잡고 `ROOT/assets/<폴더>/` 와 `ROOT/docs/previews/` 에 씁니다. 그래서 어디서 실행해도 되고, `tools/` 폴더를 통째로 다른 게임 루트로 복사하면 그대로 동작합니다. 임시 파일은 `tools/fx/_cache/`, `tools/audio/_cache/` (`.gitignore`의 `/tools/**/_cache/`).
3. **폴더마다 매니페스트 조각.** 결과 폴더마다 `manifest.json` (CONTRACT §2 형식: `atlases`, `images`, `spritesheets`, `sprites`, `nineSlice`, `audio`, `audioGroups`). 경로는 전부 `assets/` 기준 상대 경로. 게임은 매니페스트로만 에셋을 찾고, 없는 키는 대체 그림으로 계속 돕니다. 알 수 없는 필드는 무시되므로 `notes`, `frameSize`, `conventions` 같은 설명용 필드를 자유롭게 넣었습니다.
4. **사람용 미리보기 + 기계용 검사 한 쌍.** 생성기는 `docs/previews/`에 시트·GIF·장면 합성을 쓰고, 검사 스크립트는 종료 코드(0 = 통과, 1 = 오류)로 판정합니다.
5. **세 가지 바닥 위에서 확인.** 미리보기는 항상 눈(`#F4F7FB`) · 광장(`#D9A08A`) · 바다(`#1F5FA8`) 세 배경 위에 그려서, 어느 바닥에서도 읽히는지 봅니다(`fxlib.save_gif(..., panels=…)` 기본값).
6. **해는 왼쪽 위.** 그림의 빛 방향은 Blender 스프라이트와 같은 "화면 왼쪽 위에서 오는 해"(CONTRACT §1): `fxlib.LIGHT = normalize([-0.55, -0.62, 0.56])`, 바닥은 `gen_ground.LXY = [-0.66, -0.75]`.
7. **UI 그림에 글자를 굽지 않는다.** 글자는 게임이 그립니다(한국어/영어 전환). 예외는 이모티콘의 Z, !, ? 모양뿐.
8. **2:1 아이소.** PPU 64 (1 m = 가로 64 px). 바닥의 세계 축 A(화면 오른쪽 아래, (2,1))로 1 m = (+45.25, +22.63) px. 바닥 그림·패드·데칼은 모두 이 투영을 따릅니다.

### 2.2 그리는 방식 — `fxlib.py`

**(a) 슈퍼샘플 캔버스.** `F.Canvas(w, h, ss=4)` 는 출력 크기 w×h 를 4배(기본)로 샘플링한 **premultiplied float RGBA** 캔버스입니다. `c.X`, `c.Y` 는 각 서브샘플 중심의 *출력 픽셀 좌표*라서, 그리는 코드는 해상도와 무관합니다. `c.image()` 가 premultiplied 채널을 LANCZOS로 줄여 PIL RGBA 를 돌려주므로 가장자리에 검은 테두리가 생기지 않습니다. 큰 부드러운 것(연기, 빛)은 `ss=2` 로 속도를 냅니다.

**(b) 부호 있는 거리 함수(SDF).** 모든 모양은 "경계까지의 거리(안쪽은 음수, 단위는 출력 px)" 배열입니다.
`sd_circle`, `sd_ellipse`, `sd_box(…, r)`(둥근 사각), `sd_segment`(캡슐), `sd_polyline`, `sd_polygon`(정확), `sd_star(…, round_)`, `sd_arc`, `sd_heart`/`sd_heart_iq`, `sd_teardrop`, `sd_glint`(오목한 4갈래 반짝이), `sd_implicit`(임의 음함수 → 근사 거리).
합치기: `union`, `subtract`, `intersect`, `smin(a, b, k)`(부드러운 합집합 — 장난감 같은 둥근 이음매의 핵심), 회전: `F.rot(X, Y, cx, cy, ang)`.

**(c) 덮임 정도(안티앨리어싱).** `c.cov(d, feather)` = `clip(0.5 - d / (px + feather))`. `c.fill(d, color, alpha, feather)` 가 덮임으로 칠합니다.

**(d) 레이어와 연산.** `c.layer()` 빈 레이어, `c.over(L, opacity, mask)`, `c.paint(cov, color, alpha)`, `c.add(...)`(가산광, 알파 유지), `c.shadow(cov, dx, dy, sigma, color, opacity)`(흐린 오프셋 그림자, 기본 네이비 `#1B2840`), `c.glow(...)`, `c.region(x0, y0, x1, y1)` = **같은 픽셀을 공유하는 부분 캔버스** — 작은 모양(반짝이, 물방울)을 전체 캔버스가 아니라 그 주변만 계산해서 시트 렌더가 빨라집니다.

**(e) "말랑한 장난감" 질감 = `toy()`.** 하우스 스타일의 핵심 함수:
```
toy(c, d, top, bot, outline, ow=3, bevel=7, gloss=0.35, shadow=0.3, hi=0.5, lo=0.45, spec=0, tint_lo=None, pillow=None, ...)
```
드롭 섀도 → 어두운 외곽선(`d - ow`) → 위→아래 그라데이션(`top`→`bot`) → `bevel_normals(d, bevel)`(SDF를 둥근 높이장으로 바꿔 법선 계산; 하트·구름처럼 능선이 생기면 안 되는 모양은 `pillow=시그마` 로 `pillow_normals`) → `lambert(n)`(평면 대비 상대 조명) → `shade(base, s, hi, lo, tint_lo)`(밝은 쪽은 흰색으로, 어두운 쪽은 `tint_lo` 색으로 — 그림자를 회색이 아니라 채도 있는 색으로) → 위쪽 광택 띠(`gloss`) → 선택적 `specular`.
`stroke(c, d, width, color)` 는 SDF 윤곽선만 그립니다. 이징: `ease_out`, `ease_in`, `bump(t, a, b)`, `clamp01`.

**(f) 이음매 없는 타일용 주기 노이즈.** `fft_noise(h, w, seed, scale | beta | band, aniso, angle)` 는 FFT로 만든 **격자 주기 노이즈**(평균 0, 표준편차 1) — 가우시안 저역, 1/f^β 프랙탈, 대역통과(물결), 방향 늘이기 지원. `worley(h, w, cells, seed)` 는 주기 셀룰러 노이즈(F1, F2, 셀 id). `blur(a, sigma, wrap=True)` 는 FFT 가우시안(타일 유지), `downsample_wrap(arr, factor)` 는 이음매를 지키며 축소합니다.

**(g) 저장·미리보기.** `save_png(img, path, quant=N, dither=…)`(libimagequant 팔레트 PNG, 알파 유지), `strip(frames)`(가로 스트립), `save_gif(frames, path, fps, panels=(눈, 광장, 바다), hold, scale, anchor)`(세 배경 나란히 + 앵커 위치에 분홍 십자), `rgba_bg`.

최소 예 (실행 확인함 — 4.4 R4의 망치 아이콘):
```python
import fxlib as F
from fxlib import toy
c = F.Canvas(96, 96)                                   # 96x96 아이콘, 4x 슈퍼샘플
d = F.sd_box(c.X, c.Y, 48, 48, 30, 20, 8)              # 둥근 사각형 SDF
toy(c, d, '#9BEA8E', '#3FAE4C', '#1F5E2A', ow=3.4, bevel=6, gloss=0.35)
c.image().save('x.png')
```

### 2.3 결과물 계열

#### 2.3.1 파티클 아틀라스 `fx_particles` (gen_fx.py `PARTICLES`)

- **흰색/회색**으로 그려 게임이 색을 입힙니다(`tintable: true`). 예외: `fx_heart`(분홍), `fx_flame`(주황), `fx_coin`(금) — 색이 구워져 있음(`tintable: false`).
- 프레임 크기: 128 px(`fx_glow`, `fx_smoke`, `fx_ring`), 96(`fx_dust`), 64(`fx_spark`, `fx_star`, `fx_snowflake`, `fx_heart`, `fx_flame`, `fx_coin`), 48(`fx_chip_wood`, `fx_chip_rock`, `fx_droplet`, `fx_wheat_bit`, `fx_leaf`).
- **트림하지 않은 정사각 프레임**(`pack_atlas(..., trim=False)`, 496×244 RGBA) — 게임의 파티클 크기 계산이 프레임 폭을 그대로 쓰기 때문. `fx_droplet` 은 위를 향함(속도 방향으로 회전).
- 게임 쪽 색 프리셋은 `src/systems/Effects.js` 의 `PRESETS`(예: `spark` 틴트 `0xffc83d…`). `gen_fx.TINTS` 가 같은 색으로 미리보기를 칠합니다.

#### 2.3.2 애니메이션 시트 (gen_fx.py `SHEETS`)
레지스트리 형식: `key: (fn, frameW, frameH, frames, fps, repeat, anchor, notes)`. 정사각이면 `fn(i, n, S)`, 아니면 `fn(i, n)`.

기법:
- **한 번 재생(one-shot)**: 시간 `t = (i + 0.7) / (n - 1 + 0.7)` 처럼 0번 프레임부터 이미 효과가 보이게(빈 첫 프레임 금지). 마지막 프레임만 거의 비어도 됨.
- **루프**: 모든 움직임을 `phase = 2π·i/n` 의 주기 함수로 → 마지막→첫 프레임 변화가 보통 프레임 변화와 같음(검사 스크립트가 비교).
- **저장**: `grid_strip(frames, 2048)` — 가로로 늘어놓되 **2048 px 넘으면 여러 줄로 감쌈**(2048 텍스처 제한 GPU 대비). 그래서 `fx_levelup`(1536×384), `fx_unlock`(1344×384)은 2줄. Phaser 스프라이트시트 로더는 줄바꿈을 자동 처리(행 우선 번호). 256색 팔레트 PNG(`quant=256, dither=0.6`).
- 솜뭉치 `ball()`, 물 `water_part()`, 반짝이 `glint()`, 별 `star5()`, 동전 `coin(theta)`, 불꽃 `flame_layers()`, 구름 `puff_sdf()+cloud()` 는 다른 시트에서도 재사용합니다(`emote_fx.py` 가 `import gen_fx as G`).

### 2.5 블렌드 교훈 — 가산(ADD) 블렌드는 눈 위에서 안 보인다

- ADD는 배경색에 RGB를 *더하는* 방식입니다. 이 게임의 바닥은 거의 흰 눈(`#F4F7FB` ≈ 0.96)이라, 더해도 이미 1.0 근처라서 잘려서 **효과가 사라집니다**. 어두운 바닥에서는 예쁘지만 밝은 바닥에서는 쓸모가 없습니다.
- 그래서 모든 시트를 **NORMAL 블렌드 그림**으로 만들었습니다: 채도 높은 속(금색·주황), 따뜻한/차가운 **어두운 테두리**(예: 반짝이 가장자리 `#B8650E`, 물 테두리 `#2F86C9`, 솜뭉치 테두리 `#A9BCD8`), 그리고 항상 눈·광장·바다 세 배경에서 미리보기로 확인.
- 매니페스트 `blend: "NORMAL"` 을 명시, `emote_check.py` 는 NORMAL이 아니면 오류로 막습니다(`'blend must be NORMAL (ADD vanishes on snow)'`).
- 게임 쪽 파티클 프리셋(`src/systems/Effects.js`)도 이 교훈에 따라 `spark`, `glow` 의 `add` 를 뺐고, 현재 `add: true` 는 `flame` 하나뿐입니다.
- 새 게임 바닥이 풀밭·흙처럼 중간 밝기여도 **기본은 NORMAL**로 유지하고, ADD는 밤 장면·어두운 광산 안 같은 곳에만 쓰세요.

### 3.2 합성 키트

- 물리 모델: `ks_pluck`(Karplus–Strong, 분수 지연으로 정확한 음정).
- 이펙트: `pan`(등전력), `chorus(wrap=)`, `echo`, **`reverb`**(8줄 FDN, Householder 피드백, 줄마다 고역 흡수, Schroeder 확산기, 블록 처리).

### 3.3 배경음악 `bgm_village` 는 이렇게 작곡됐다 (`music.py`)

- **조성·빠르기**: F 장조, 100 bpm, 스윙 0.58(`Song(100, swing=0.58, seed=11)`), 4/4, **32마디 = 76.8초**.
- **형식**: A1 A2 B A3 (각 8마디).
  - A 화성: `F | Dm | Bb | C | F | Dm | Bb C | F` (I vi IV V).
  - B 화성: `Bb | C | Am | Dm | Bb | C | Gm7 | C7`.
  - **후크**(F 장조 5음 음계): `"A4 C5 D5 - C5 A4 C5 -"` (`MEL_A[0]`). 멜로디는 마디마다 8분음표 8칸 문자열(음 = 새 음, `-` = 늘임, `.` = 쉼)로 적혀 있어 고치기 쉽습니다.
  - 마지막 마디 `MEL_A_TURN = "F4 - - - . . F4 G4"` + 화성 `F → C7` 이 다시 후크로 넘어가는 못갖춘마디 역할 → 루프가 자연스러움.
- **악기 배치**:
  - A1: 마림바 리드, 킥 1·3박, 셰이커 8분, 뜯는 현 오프비트 "칙-카" 반주, 피치카토 베이스, 따뜻한 패드.
  - A2: + 뮤직박스가 한 옥타브 위로 겹침, 브러시 스네어 2·4박, 베이스 워킹, 가끔 킥 추가.
  - B: 오카리나 리드(긴 음엔 마림바 잔향), 뜯는 현 아르페지오, 패드 크게, 썰매 방울 2·4박, 2마디마다 뮤직박스 반짝 아르페지오.
  - A3: 마림바 + 뮤직박스 + 글로켄슈필 대선율(`COUNTER_A3`) + 썰매 방울.
  - 장식: 7·31마디 우드블록, 15마디 탐 필인 + 심벌 스웰로 B 진입, 23마디 스네어 롤, 0·16·24마디 심벌.
- **믹스**: 버스별 게인·리버브 센드(`gains`, `sends`), 패드 버스에 코러스, 공유 FDN 리버브(rt60 1.9 s, 프리딜레이 22 ms), 마스터 EQ(32 Hz 고역통과, 110 Hz −2.5 dB 저역 셸프, 8 kHz −1 dB, 15 kHz 저역통과). 사람 연주 같은 흔들림 `song.hum()`, `song.vel()`.
- **마무리 `finish(mix, L)`**: `fold_loop` 로 꼬리를 앞으로 접기 → 원형 버스 컴프레서(−24 dB, 1.7:1) → −18 LUFS로 → **원형** 리미터 −1.6 dB.
- **`bgm_title`**: 84 bpm, 스윙 0.53, 8마디(22.86초), 뮤직박스가 후크를 한 옥타브 위에서, 하프 아르페지오(`pluck`, t60 2.2), 4마디부터 오카리나, 패드·베이스·썰매 방울·글로켄, rt60 2.3.
- 렌더 함수 인터페이스(새 곡도 똑같이): `render_x(seed, loop_samples=None, premix_only=False) -> (stereo (2, L), meta)`, `meta = {"bpm", "bars", "loopSamples", "nominalSamples", "target"}`.

### 3.4 환경음 (`ambience.py`) — "만들 때부터 이음매 없음"
- `amb_wind`(24초): 바람 세기 곡선(`periodic_curve`)을 따라 중심 주파수가 260–980 Hz로 움직이는 분홍빛 노이즈 + 공명 "우우" 소리(Q 13) + 4.2 kHz 이상 눈 쓸리는 소리 + 낮은 울림, 오른쪽 채널이 0.45초 늦게 따라와 움직이는 느낌. −20 LUFS.
- `amb_sea`(24초): 파도 4번(0.3/6.2/12.4/18.0초; 부풀기 → 2.3초에 부서짐 → 거품 지글 → 물러남), 좌우 번갈아, `fold_loop`, 밑에 잔잔한 파도 바닥. −20 LUFS.
- `amb_fire`(20초): 낮은 불길·숨·쉿 소리 바닥을 느린 곡선 + 깜빡임 곡선으로 변조, 장작 튀는 소리(초당 7.5회: 4% 큰 "탁", 20% "딱", 나머지 "틱") + 잔 튐 초당 35회. −21 LUFS.
- 원칙: 연속 바닥은 `noise_fft`(주기), 모든 변조는 루프 길이의 정수 주기(`periodic_curve`), 시간변화 필터는 루프 끝으로 미리 돌림(`circ_tv`, `filt_circ`), 사건(파도·튐)은 끝을 넘겨 그린 뒤 `fold_loop`, 마지막 리미터는 `circular=True` (`master_loop(x, target_lufs)`).

### 3.5 효과음 (`sfx.py`)
- 설계 = **겹치기**: 짧은 타격(클릭·딱) + 몸통(모달 공명, 음 떨어지는 쿵, 종 배음) + 결(노이즈 스윕, 바스락, 거품) + 선택적 짧은 방 잔향.
- 도우미: `Mono`(모노 믹스 버퍼), `mix`, `blip(f0, f1, …)`(음이 미끄러지는 사인), `burst`(필터 노이즈 터짐), `puff`, `bubble`(민나에르트 거품 "뽁"), `nsweep`(대역 노이즈 스윕 = 휙·쉭), `chime`, `coin_hit`, `soft_square`, `sparkles`(F 장조 5음 음계 `PENT_HI` 뮤직박스 반짝), `room`, `smooth_noise`.
- 레지스트리: `SFX = {key: 함수}` (함수는 모노 배열 반환), 변형은 `lambda: sfx_chop(1)` 처럼.
- 마스터링 `render(key)`: `FINISH[key]["punch"]` dB 만큼 3 ms 리미터로 눌러 휴대폰 스피커에서 단단하게 → `S.finish_sfx(peak_db=-1.5)`.
- 음악적 효과음(동전, 해금, 레벨업, 고용, 완성)은 배경음악과 같은 **F 장조**. `sfx_pickup` 은 정확히 **C5(523.25 Hz)** 에 안착하는 "톡" — 게임이 쌓인 개수에 따라 재생 속도를 올립니다(`Game.js`: `rate: 0.9 + min(0.9, count * 0.045)`). `sfx_complete`(4.15초)는 마을 후크를 금관·글로켄 팡파레로 인용. `sfx_customer_happy` 는 `formant_voice` 로 만든 귀여운 "야!" + 뮤직박스(가장 모험적인 소리 — 사람이 꼭 들어볼 것).
- 작업 소리 `sfx_saw`, `sfx_smelt`, `sfx_sizzle`, `sfx_oven` 은 0.8–0.9초 **한 번 재생**(루프 아님): 게임이 가공 1회마다 400 ms 간격 제한으로 재생(`Station.js`).

### 3.6 루프 이음새 — 3단계 방어

1. **내용 자체가 주기적**(3.3–3.4): `fold_loop`, 주기 노이즈·곡선, 원형 컴프레서·리미터.
2. **휴먼라이즈 음의 앞잘림 방지**: 사람 같은 타이밍 흔들림으로 t<0 이 된 음은 공격이 잘려 루프 시작에서 "틱" 소리가 났습니다. `music.Mixer.add()` 가 t<0 인 사건을 `t + loop` 로 옮겨 `fold_loop` 이 경계를 넘겨 이어 붙이게 고침 → 경계 2차 차분 비율 1.08 → 0.07 (보고서).
3. **크롬의 OGG 패딩 발견과 블록 경계 맞추기**:
   - Vorbis 인코더는 마지막 블록을 채우고 "끝에서 N샘플 버려라(end-trim)" 표시를 남깁니다. **Chromium의 `decodeAudioData` 는 이 표시를 무시**해서 루프마다 32–960샘플(최대 약 22 ms)의 쓰레기 패딩이 붙었습니다(헤드리스 Chromium 141에서 확인). Phaser는 버퍼 전체 길이로 루프를 반복하므로 매 바퀴 틈/딸깍.
   - 해결 `build_audio.fit_loop(key)`: 렌더 → 임시 OGG 인코딩 → `ffmpeg_tools.ogg_tail()` 로 마지막 패킷의 `discard_padding`(ffprobe "Skip Samples")과 끝부분 패킷 시작점(= 블록 경계)을 읽음 → **명목 길이에 가장 가까운 블록 경계를 새 루프 길이로** → 패딩이 0이 될 때까지 반복(최대 10회).
     - 음악: 연주는 한 번만 렌더(`premix_only=True`)하고 접는 지점만 옮김 → `bgm_village` −64샘플(1.5 ms), `bgm_title` +320샘플(7 ms). 다운비트가 몇 ms 빨라지거나 늦을 뿐 들리지 않음.
     - 환경음: 새 길이로 다시 생성(모든 것이 L 주기라 가능). 현재 `amb_wind`/`amb_sea` 1,058,432, `amb_fire` 882,048샘플.
   - 결과(2026-10-07 재확인): 5개 루프 모두 OGG 패딩 0, OGG와 MP3 모두 정확히 `loopSamples` 로 디코드됨.
   - 블록 경계는 libvorbis 빌드에 따라 다를 수 있음 → 다른 PC/다른 ffmpeg 에서는 반드시 다시 빌드하고 검사 통과 확인.
   - MP3: LAME 무갭 헤더(인코더 지연 576 + 디코더 지연 529 = **1105** = 매니페스트 `mp3StartPad`). 이 헤더를 무시하는 디코더(일부 사파리)는 앞에 1105샘플을 붙입니다. 게임 `src/core/Audio.js` 의 `trimLoops()` 가 디코드된 루프가 `duration` 보다 10 ms 넘게 길면 `mp3StartPad` 위치부터 정확한 길이로 잘라 냅니다.
   - 주의(6장): `trimLoops()` 는 **앞을 자릅니다** — MP3엔 맞지만 OGG 끝 패딩엔 틀림. 그래서 OGG 패딩 0 유지가 필수(검사가 강제).

### 3.7 음량 — 파일은 크게, 매니페스트 `volume` 으로 맞춤
- 파일은 "뜨겁게" 마스터링: 효과음 피크 −1.5 dBFS, 음악 −18 LUFS, 환경음 −20/−21 LUFS.
- `build_audio.SOUNDS[key] = (kind, loop, target, extra)` 의 `target` = 게임 호출 볼륨 1일 때의 목표 음량(음악·환경음은 적분 LUFS, 효과음은 최대 순간 LUFS 400 ms). 측정은 디코드된 OGG를 ffmpeg `ebur128` 로(모노는 듀얼 모노, 짧은 파일은 0.5초 패딩).
- `volume = clamp(10 ** ((target + HEADROOM_DB - 측정값) / 20), 0.05, 1.0)`, `HEADROOM_DB = -2.0`(WebAudio는 소리를 더하다 0 dBFS에서 잘리므로). 예: `bgm_village` −18 LUFS, 목표 −24.5 → 0.376.
- 목표값: 음악 −24.5(마을)/−23.5(타이틀), 환경음 −32.5~−31, 효과음 −20(`sfx_pad_fill`)~−14(`sfx_complete`).
- 현재 volume(일부): `bgm_village 0.376, bgm_title 0.422, amb_wind 0.193, amb_sea 0.188, amb_fire 0.295, sfx_chop_* 0.85–0.90, sfx_click 0.977, sfx_coin 0.447, sfx_build 0.49, sfx_complete 0.519, sfx_saw 0.282`.
- 게임은 `volume × 호출 볼륨` 으로 재생: 발소리 ×0.32(`Player.js`), 작업장 소리 ×0.45 + 520 px 안에서만(`Station.js`), 환경음은 `Audio.setAmbience(key, 0..1)` 로 거리에 따라 페이드(`Game.js`). 이렇게 해서 주요 효과음이 음악+환경음보다 약 7 dB 위, 발소리·작업장 소리는 살짝 아래.
- 코덱 피크 초과 방지: 인코딩 후 디코드 피크가 −1 dBFS(`PEAK_MAX`)를 넘으면 게인을 낮춰 최대 4번 재인코딩.
- 형식: OGG Vorbis q4 + MP3(음악 128 kbps 스테레오, **환경음 80 kbps 모노**, 효과음 96 kbps 모노), 44.1 kHz. 환경음은 나중에 메모리 때문에 모노로 바꿨습니다 — 게임이 루프를 PCM으로 미리 디코드하는데 스테레오 24초 3개가 약 23 MB였음(`CHANNELS` 주석). 음악은 스테레오 유지.
- 페이로드: 현재 4.73 MB(한도 8 MB).

#### R1. 새 효과음 — 예: 건물 완공 `sfx_building_done`

```python
def sfx_building_done():
    """Building finished: two hammer knocks -> wooden 'thunk' -> short F-major glock/brass flourish + sparkles."""
    r = S.rng(4100)                                    # 키마다 고유 시드
    m = Mono(2.0)
    for k, tt in enumerate((0.0, 0.14)):
        m.add(tt, S.modal(520 * (1, 1.08)[k], n_of(0.2), [(1, 1, 0.1), (1.73, 0.5, 0.06), (2.6, 0.35, 0.04)], r), 0.5)
        m.add(tt, burst(r, 0.02, 2500, 1.0, tau=0.0025), 0.6)
    m.add(0.30, blip(180, 90, 0.25, 0.03, 0.06), 0.7)               # 묵직한 나무 "쿵"
    for i, mm in enumerate([65, 69, 72, 77]):                      # F4 A4 C5 F5 (배경음악과 같은 F 장조)
        m.add(0.42 + i * 0.07, I.glock(mm + 12, 0.7, r), 0.35)
        m.add(0.42 + i * 0.07, I.brass(mm, 0.7, 0.18), 0.12)
    sparkles(m, r, 0.75, 6, 0.07, 0.16)
    return room(m.x, 0.8, 0.12, 0.4, 0.7)
```

#### R3. 새 작업 소리 루프 (환경음 방식) — 예: 제재소 `amb_sawmill`
새 모듈 `tools/audio/work_amb.py` (확인: 0.7초 렌더, 경계 `hf_ratio 0.005`, `d2_ratio 0.006` — 1.0 미만이면 통과):
```python
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import deps; deps.ensure()
import numpy as np
import synth as S, sfx as X
from synth import SR, n_of

def amb_sawmill(seed=71, dur=12.0, loop_samples=None):
    """Work loop: 16 saw strokes per loop + soft wood bed. Seamless: periodic bed, strokes folded, circular limiter."""
    r = S.rng(seed)
    L = int(loop_samples) if loop_samples else n_of(dur)
    bed = S.filt_circ(S.noise_fft(L, r, lambda f: 1.0 / np.maximum(f, 60)), 'lp', 1800) * 0.03
    buf = np.zeros(L + n_of(2.0))
    period = L / SR / 16                                   # 루프 안에 정수 번 → 이음새 없음
    for k in range(16):
        y = X.nsweep(r, period * 0.9, 900, 2600, 2.5, [(0, 0), (0.05, 1), (period * 0.8, 0.6), (period * 0.9, 0)])
        i = n_of(k * period)
        buf[i:i + len(y)] += y * (0.5 + 0.1 * (k % 2))
    loop = S.fold_loop(buf, L)[0] + bed
    loop = loop - loop.mean()
    loop = loop * S.undb(-21.0 - S.lufs(loop))
    loop = np.stack([loop, np.roll(loop, n_of(0.011))])   # (2, L) 로 반환해야 함 — fit_loop 이 x.shape[1] 을 읽음
    return S.limiter(loop, -1.5, window_ms=5.0, circular=True), {'loopSamples': L}
```
등록: `build_audio.LOOPS["amb_sawmill"] = ("work_amb", "amb_sawmill")`, `SOUNDS["amb_sawmill"] = ("ambience", True, -31.0, {})`, `check_audio.CONTRACT["ambience"]`.
주의(직접 겪음):
- 렌더 함수는 `loop_samples` 인자를 받아 **그 길이의 주기 신호**를 만들어야 합니다(`fit_loop` 이 길이를 바꿔 다시 부름).
- **1차원(모노) 배열을 반환하면 `fit_loop` 이 `IndexError` 로 죽습니다** → 항상 `(2, L)`.
- 길이를 그냥 12초로 두면 OGG 끝 패딩이 784–912샘플 생겼습니다 → 반드시 `LOOPS` 에 등록해 `fit_loop` 을 거치고, 4.2 ③을 먼저 고치세요.

    """Construction dust: warm cotton balls roll out sideways along the ground, swell and fade. Anchor = ground."""
    t = (i + 0.7) / (n - 1 + 0.7)                          # 0번 프레임부터 이미 보이게

```python
def tex_cobble():
    """Cobbled road: periodic Worley cells shrunk into rounded stones over gravel mortar."""
    ss = 2
    X, Y = coords(N, ss)
    rgb = np.broadcast_to(hexc('#8A7A6A'), X.shape + (3,)).copy()          # 줄눈 / 자갈
    F1, F2, ID = worley_xy(X, Y, N, N, 24, seed=601, jitter=0.7)            # 토러스 위 셀 → 이음매 없음
    edge = (F2 - F1) * 0.5                                                  # 셀 경계까지 거리
    d = 2.2 - edge                                                          # 돌 = 셀을 2.2 px 줄인 것
    cov = np.clip(0.5 - d * ss, 0, 1)
    hgt = np.sqrt(np.clip(-d / 6.0, 0, 1)) * 5.0
    lit = relief(hgt, ss, 1.2)                                              # 공용 해 방향 음영
    tone = np.random.default_rng(602).uniform(0, 1, 24 * 24).astype(np.float32)[ID]
    col = F.mix(hexc('#9DA3AD'), hexc('#C2C6CC'), tone)
    col = lerp3(col, hexc('#EEF2F7'), np.clip(lit, 0, 1) * 0.6)
    col = lerp3(col, hexc('#4A4F5A'), np.clip(-lit, 0, 1) * 0.6)
    rgb = lerp3(rgb, col, cov)
    return finish(rgb, ss)
```
등록: `TEXTURES['ground_road_cobble'] = (tex_cobble, 'Cobbled road, seamless.')`; `check_assets.GROUND_TILES` 에 추가. `python3 tools/fx/gen_ground.py --only ground_road_cobble` → `_cache/ground_only.png`(2×2 타일). 규칙: **비주기 함수 금지**(일반 `np.random` 점 찍기 대신 `fft_noise`/`worley_xy`/`periodic_conv`), 방향 무늬는 512에서 정수 번 감기게(`ROW_P` 방식), 끝에 `finish()` 가 `downsample_wrap` 으로 줄임. 텍스처 함수는 PIL이 아니라 **float RGB 배열 (N, N, 3)** 을 반환합니다(데칼은 `OVERLAYS` 에 PIL RGBA 반환 + `(fn, anchor, kind, notes)`).

- 세틀러식은 한 판이 길어서 곡이 더 필요합니다(차분한 건설, 바쁜 생산, 밤, 승리). R2로 만들되, **WebAudio는 소리를 float32 PCM으로 풀어서 메모리에 올립니다**: 1초 모노 ≈ 176 KB → `bgm_village`(76.8초 스테레오) ≈ 27 MB, 24초 모노 환경음 ≈ 4.2 MB. 곡은 장면별로 불러오고 내리기, 작업 루프는 8–12초 모노로 짧게.

## 7. 빠른 참조

**레지스트리(새 키를 등록하는 곳)**
| 계열 | 파일 · 이름 | 형식 |
|---|---|---|
| 파티클 | `gen_fx.PARTICLES` | `key: (fn() -> PIL, tintable, notes)` |
| 이펙트 시트 | `gen_fx.SHEETS` | `key: (fn(i, n, S), frameW, frameH, frames, fps, repeat, anchor, notes)` |
| UI 아이콘 / 기타 | `gen_ui.ICONS`, `ATLAS_ITEMS`, `ANCHORS`, `NOTES` | `key: fn() -> PIL` |
| 9-slice | `gen_ui.NINE` | `key: (fn, dict(left, right, top, bottom))` |
| 바닥 텍스처 | `gen_ground.TEXTURES` | `key: (fn() -> float RGB (512, 512, 3), notes)` |
| 바닥 데칼·띠 | `gen_ground.OVERLAYS` | `key: (fn() -> PIL RGBA, anchor, kind, notes)` |
| 이모티콘 | `emote_art.EMOTES` | `[(key, fn(c), notes)]`, 64-px 단위 |
| 사회적 이펙트 | `emote_fx.SHEETS` | `key: (fn(i, n), frameW, frameH, frames, fps, repeat, anchor, notes)` |
| 효과음 | `sfx.SFX`, `sfx.FINISH` | `key: fn() -> mono ndarray`; `key: dict(punch=dB, fout=s)` |
| 루프(음악·환경음) | `build_audio.LOOPS` | `key: (module, fn)`; fn(`loop_samples=`) → `((2, L), meta)` |
| 소리 목록·음량 | `build_audio.SOUNDS`, `GROUPS` | `key: (kind, loop, target_LUFS, extra)` |
| 검사 기준 | `check_assets` 목록들, `emote_check` 목록들, `check_audio.CONTRACT` | 키 이름 리스트 |

**자주 쓰는 명령 (게임 루트에서)**
```bash
python3 tools/fx/gen_fx.py --only fx_build_dust     # 새 이펙트 다듬기 (에셋 안 건드림)
python3 tools/fx/gen_ui.py && python3 tools/fx/gen_fx.py && python3 tools/fx/gen_ground.py && python3 tools/fx/check_assets.py
python3 tools/fx/gen_emotes.py                      # emote_check 자동
python3 tools/audio/sfx.py sfx_building_done        # 새 효과음 한 개 렌더해 보기
python3 tools/audio/build_audio.py --only sfx_building_done
python3 tools/audio/build_audio.py --skip-render    # 음량 목표만 바꿨을 때
python3 tools/audio/demo_mix.py                     # 사람용 30초 믹스
```
