# 기획 결정 기록 (07번 기획 초안 17절 질문에 대한 대표님 답)

> 질문을 하나씩 정하는 대로 여기에 적는다. 다 정해지면 `docs/기획서.md` 로 정리한다.

| 번호 | 질문 | 결정 | 날짜 |
|---|---|---|---|
| 1 | 화면 방향 | **가로 화면** (추천대로). 세로는 나중에 추가 가능 | 2026-10-07 |
| 2 | 싸움 | **다른 마을과 경쟁** (초안 추천과 다름). 컴퓨터가 움직이는 이웃 마을(AI 상대)과 땅을 다툼 → 상대 마을 두뇌, 경쟁 방식은 **평화 경쟁**: 서로 공격하지 않고 온기·영향력으로 빈 땅을 먼저 차지하거나 봉화를 먼저 밝히는 시합. 우리 온기가 더 강하면 상대 땅도 넘어올 수 있음. 군인·싸움 그림은 만들지 않음 | 2026-10-07 |
| 4 | 촌장 직접 걷기 | **둘 다**: ① 하늘에서 내려다보며 짓는 '건설 보기'와 ② 촌장이 지도를 걸어 다니며 주민을 응원하는 '촌장 보기'를 버튼으로 바꿀 수 있게. 촌장을 안 써도 게임은 진행됨 | 2026-10-07 |
| 5 | 깃발 꽂기 | **자동이 기본(2칸마다), 설정에서 끄면 직접** (추천대로) | 2026-10-07 |
| 6 | 코인의 역할 | **건설은 물건으로, 코인은 배·레벨업·장식·연장 + 카드 뽑기**. 대표님 제안: 코인으로 카드를 뽑는 재미 추가. 카드 내용: **특별 주민, 장식·건물 꾸미기, 일 잘하는 능력 카드(경쟁이 싱거워지지 않게 세기 조절), 물건 꾸러미** 모두. (주의: 나중에 진짜 돈으로 뽑기를 팔면 한국 법상 확률 공개 의무가 있음) | 2026-10-07 |
| 3 | 지역 구조 | **한 지도를 계속 넓히기 (오픈월드식)**. 초안 추천(챕터마다 새 지도)과 다름 → 휴대폰 성능(주민 수백 명 + 넓은 지도)을 계약서·시제품 단계에서 먼저 확인해야 함 | 2026-10-07 |
