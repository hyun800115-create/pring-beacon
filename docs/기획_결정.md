| 11 | 연장 만들기 | **자동이 기본(필요한 연장부터), 원하면 직접 고르기** (추천대로) | 2026-10-07 |

## 질문 밖에서 정한 것
| 항목 | 결정 | 날짜 |
|---|---|---|
| 자원 | **나무, 돌, 철광석, 은광석, 금광석** (대표님 지정). 음식: **물, 생선, 고기, 빵, 그 밖에 다양한 요리**(예: 구운 생선·구운 고기·수프·생선 통조림 등, 요리 목록은 기획서에서 제안). 서리마을에 이미 있는 그림: 통나무·판자·밀·빵·광석·주괴·생선(날것/구운 것)·고기(날것/구운 것)·코인. 새로 그릴 것: 돌, 은광석, 금광석, 물 등 | 2026-10-07 |
| 식재료 키우기 | **식재료를 직접 키우는 재미도 넣는다** (대표님 요청). 네 가지 모두: **밭농사**(밀·감자·당근·양배추 등, 자라는 모습 보임), **가축 — 가능한 모든 '동물→생산물' 줄**(대표님 요청. 예: 닭→달걀, 젖소→우유, 소→고기, 양→털, 돼지→고기, 오리→달걀·깃털, 염소→우유·치즈 등), **양식장·낚시터**, **과수원·벌집**(사과·베리·꿀). → 건물·아이템 수가 크게 늘어나므로 출시 1판/이후 판으로 나눠 넣는 순서를 기획서에서 제안 | 2026-10-07 |
| 생산 줄 | **생산 시설이 줄줄이 이어지는 구조**(대표님 강조). 예: 밀밭 → 풍차(밀가루) → 빵집(빵), 젖소 → 우유 → 치즈 공방, 광산 → 용광로 → 대장간(연장). 모든 식재료·자원이 이런 줄로 이어지게 설계 | 2026-10-07 |
| 외부 상인 | **바깥에서 상인이 찾아와 특별한 물건·생활용품·미술품 등을 판다**(대표님 요청). 코인으로 구매. 마을에서 못 만드는 물건을 들여오는 통로이자 코인 쓰는 곳. 상인 종류·오는 주기·파는 물건은 기획서에서 제안 | 2026-10-07 |
| 플랫폼 | **PC 버전 + 스마트폰 안드로이드 APK 를 같이 만든다.** 같은 게임 코드(Phaser 웹 게임) 하나로, PC 는 설치형 프로그램으로 포장, 안드로이드는 APK 로 포장(Capacitor 예정). 시험은 계속 플레이 링크로도 한다. APK 를 만들려면 이 PC 에 자바(JDK)와 안드로이드 SDK 설치가 필요(시제품 단계에서 설치) | 2026-10-07 |

## 마을 생활 (2026-10-07 대표님 요청 — "심즈 같은 세상")

|---|---|
| 화면 | 확대·축소 자유롭게 (손가락 벌리기, 마우스 휠, 버튼) |
| 시작 | **마차에 이주민들이 타고 시작**. 마차에 기본 자재와 식량. 주변에 정착지를 정하면 **마을회관**을 세우며 시작. 첫 주민들의 일은 알아서 정해짐 |
| 주택 | **오두막으로 시작해서 업그레이드**. 집이 커지면 인구 수용 증가 |
| 이주민 | 이주민이 찾아오면 **받기 / 안 받기** 선택. 받으면 **스스로 기존 오두막 근처에 오두막을 지어** 생활. 나중에 대표님이 옮길 수도 있음 |

| 표현 | 주민이 **힘든 척, 하기 싫은 척, 좋은 척, 씩씩한 척** 등 자유롭게 감정 표현. 일하는 모습은 생생하게 |

| 행사 | **결혼식 마을 잔치, 출산 축하, 주민 사망 시 장례식** |
