# 이사 키트 — 서리마을 도구를 새 프로젝트(세틀러식 게임)로 옮기기

> 이 폴더는 **서리마을 개척기**를 만들 때 쓴 모든 도구·자료·노하우를 새 프로젝트로 옮기기 위한 "이사 키트"예요.
> 새 프로젝트에서 Claude가 이 키트만 읽으면, 지금까지와 똑같은 방식(Blender 3D 렌더 → 스프라이트, 직접 합성한 소리, Phaser 게임, 자동 테스트, 배포)으로 바로 이어서 만들 수 있어요.

## 먼저 알아두실 것
- 지금까지 작업은 **대표님 컴퓨터가 아니라 클라우드 컴퓨터**(Claude Code가 빌려 쓰는 임시 컴퓨터: CPU 4개, 메모리 15GB)에서 돌렸어요. 새 프로젝트도 같은 방식(클라우드)으로 하면 그대로 됩니다.
- 원하시면 대표님 PC에서도 돌릴 수 있어요. Blender 그림 스크립트는 `blender -b -P 스크립트.py` 로 PC의 Blender에서 그대로 돌아가요. (자세한 건 `docs/02_도구와_환경.md`)
- AI 그림/음악 모델은 클라우드에서 다운로드가 막혀 있어서 쓰지 않았어요. 모든 그림은 **진짜 Blender로 렌더링**, 모든 소리는 **프로그램으로 직접 합성**했어요. 그래서 저작권 걱정이 없는 우리 것이에요.

## 옮기는 방법 (제일 쉬운 방법)
1. GitHub에서 **새 저장소**를 만들어요. (예: `settlers-game`)
2. Claude Code에서 그 새 저장소로 **새 세션**을 시작해요. (클라우드 환경, 네트워크 설정은 기본값 그대로)
3. 첫 메시지로 아래 글을 **그대로 복사해서** 보내요.

```
hyun800115-create/nurient 저장소의 ccr-d4ece854-h4aw8v 브랜치에 있는
frost-village/handoff/ 이사 키트를 이 저장소로 옮겨줘.
frost-village/handoff/make_kit.sh 를 실행해서 키트를 만들고, 그 내용을 이 저장소 맨 위에 넣어줘.
그다음 CLAUDE.md 를 읽고 환경 설정(Blender, 파이썬, 사운드 도구)부터 해줘.
```

4. 옮겨지면 이렇게 말하면 돼요: **"docs/handoff/07_세틀러식_새게임_기획초안.md 읽고 같이 기획부터 정하자"**

> 만약 이 브랜치가 main 에 합쳐졌다면, 위 문장에서 `ccr-d4ece854-h4aw8v 브랜치` 를 `main 브랜치` 로 바꾸면 돼요.
